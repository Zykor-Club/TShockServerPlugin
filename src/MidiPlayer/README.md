> 在添加本插件到ServerPlugin文件夹前，请确保你已经安装了相应依赖

## 功能概述

- 通过 DryWetMidi 解析 MIDI 文件，映射到泰拉瑞亚游戏内乐器播放

- 支持全服共享播放、全服点歌队列、点歌人显示与静默免打扰

- 支持八音盒绑定：管理员可绑定一个八音盒，全服播放随其开关联动，且绑定盒不可被破坏

- 全服播放时新玩家加入会从当前进度收听，点歌列表与全服状态同步

- 全服播放中所有玩家下线后自动移除当前歌曲并停止队列，玩家重新加入后 5 秒恢复队列

- 按 style 做同 tick 合并、同 style 重触发门控和每 tick 发包预算，缓解截断与爆音

- 使用 DryWetMidi 的 `Chord` 对象识别吉他和弦，识别失败时回退到时间分组

- 读取 `InstrumentNameEvent` / `ProgramNameEvent` 辅助主旋律轨道识别

- 使用 `GetDuration<TTimeSpan>()` 获取 MIDI 总时长

- 音符模型保留原始 `NoteName` / `Octave` 元数据

## 指令

| 语法                        |         权限        | 说明                                      |
| ------------------------- | :---------------: | --------------------------------------- |
| /midi                     |  midiplayer.play  | 显示帮助页面                                  |
| /midi play <文件名或编号> \[音量] |  midiplayer.play  | 播放 MIDI，播放中自动加入队列                       |
| /midi stop                |  midiplayer.play  | 停止播放并清空队列                               |
| /midi pause               |  midiplayer.play  | 暂停播放                                    |
| /midi resume              |  midiplayer.play  | 恢复播放                                    |
| /midi list \[页码]          |  midiplayer.play  | 列出可用 MIDI 文件                            |
| /midi allon               |  midiplayer.admin | 开启全服共享播放并清空个人播放状态                       |
| /midi alloff              |  midiplayer.admin | 关闭全服共享播放并清空全服队列与个人状态                    |
| /midi bind                |  midiplayer.admin | 进入绑定模式，右键八音盒完成绑定（30秒内有效，仅玩家可用）          |
| /midi unbind              |  midiplayer.admin | 解除当前世界的八音盒绑定（控制台可用）                     |
| /midi plist \[页码]         |  midiplayer.play  | 查看当前播放模式与播放队列                           |

> \[!NOTE]
> 控制台（`TSPlayer.Server`）不可执行需要玩家实体交互的命令：`play`/`stop`/`pause`/`resume`/`silent` 及 `bind`。其余命令（`list`/`allon`/`alloff`/`unbind`/`plist`/`dlist`/`merge`/`limit`）可在控制台使用。

## 文件结构

开服后自动在 `tshock/` 下创建 `MidiPlayer/` 主文件夹：

```
tshock/
└── MidiPlayer/
    ├── MidiPlayerConfig.json    # 配置文件
    ├── InstrumentMap.json       # 乐器映射表配置
    └── MidiSongs/               # MIDI 文件目录
```

## 配置

配置文件路径：`tshock/MidiPlayer/MidiPlayerConfig.json`

```json
{
  "音量校准": {
    "Harp": 1.33,
    "Bell": 1.20,
    "GuitarAxe": 1.13,
    "Drum": 0.50,
    "Guitar": 0.45
  },
  "预发送提前量(毫秒)": 5,
  "Bell同奏开关": true,
  "竖琴残响开关": true,
  "配置版本": 3,
  "每tick最大音符数": 10,
  "同Style重触发间隔(毫秒)": 35,
  "启用重复音符合并": true,
  "启用音符限流": true,
  "启用自动微调": false,
  "移调微调(半音)": 0,
  "需微调歌曲": [],
  "屏蔽手弹乐器音(防MIDI音高污染)": true
}
```

旧配置 `MidiPlayerConfig.json` 或 `MidiPlayerSurroundConfig.json`（位于 `tshock/` 根目录）会在首次加载时自动迁移到 `MidiPlayer/` 文件夹并删除原文件。

### 映射说明

| 表      | 说明                                          |
| ------ | ------------------------------------------- |
| 乐器映射表  | 128 个 GM 乐器编号(0-127) 对应的泰拉瑞亚乐器，服主可调整任意编号的映射 |
| 鼓组映射表  | GM 鼓音符到泰拉瑞亚鼓音色(Style)的映射                    |
| 吉他和弦定义 | 和弦识别时根音/音程对应的预录和弦音色(Style)                  |

- 乐器可选值：`Harp`(竖琴)、`Bell`(铃铛)、`GuitarAxe`(吉他斧)、`Guitar`(吉他和弦)、`Drum`(鼓组)

- 删除 `InstrumentMap.json` 后重启服务器可重新生成默认配置

- 修改后执行 `/reload` 即可生效，无需重启服务器

## 配置说明

| 配置项             | 类型  |  默认值  | 说明                                       |

| 音量校准            | 对象  |   -   | 各乐器的音量倍率                                 |
| 预发送提前量(毫秒)      | 整数  |   5   | 提前发包量，用于补偿网络延迟                           |

| 配置版本            | 整数  |   3   | 配置迁移版本                                   |
| 每tick最大音符数      | 整数  |   10  | 每个游戏 tick 每位玩家最大发包数                      |
| 同Style重触发间隔(毫秒) | 整数  |   35  | 吉他/鼓同 style 最短重触发间隔                      |
| 启用重复音符合并        | 布尔值 |  true | 同一时间窗口内合并相同音高音符                          |
| 启用音符限流          | 布尔值 |  true | 限制同 style 音符数量，缓解截断与爆音                   |
| 启用自动微调          | 布尔值 | false | 总开关：开启后仅对“需微调歌曲”中的曲子做整曲移调                |
| 移调微调(半音)        | 整数  |   0   | 在自动微调基础上手动微调整体音高                         |
| 需微调歌曲           | 数组  |  \[]  | 需自动微调的 MIDI 文件名列表（用 `/midi add <编号>` 添加） |

## 播放说明

- MIDI 文件目录：`tshock/MidiPlayer/MidiSongs`

- 支持 `.mid` 文件，播放时自动解析并缓存元数据

- 同一玩家播放中再次执行 `/midi play` 会加入播放队列

- 全服模式下队列为服务器共享，同一 MIDI 不能重复添加，队列会显示点歌人

- 全服模式下管理员可以移除任意点歌，普通玩家只能移除自己点播的歌曲

- `/midi slient` 可在全服播放时开启静默免打扰，切换播放模式不会清除静默状态

- 全服播放状态由服务器统一维护，新加入玩家会自动从当前播放进度开始接收后续音符

- 全服播放期间所有玩家下线时，当前歌曲会被移除，点歌队列停止推进，玩家重新加入后 5 秒恢复队列

- 播放开始/结束时显示浮动文字：单人模式在玩家头顶上方 2 格，全服模式在绑定八音盒上方 3 格（未绑定则回退到各玩家头顶），文字颜色随机

## 八音盒绑定说明

- 通过 `/midi bind` 进入绑定模式后，右键目标八音盒即可完成绑定（30 秒超时自动退出，再次输入 `/midi bind` 可取消）

- 绑定数据按世界保存于 `tshock.sqlite` 数据库，切换世界/重启服务器后自动恢复对应世界的绑定

- 全服共享播放模式下，绑定八音盒的开关会联动全服播放：打开 → 恢复播放，关闭 → 暂停播放

- 绑定八音盒不可被挖掘、替换或爆炸破坏（防摧毁）

- 通过 `/midi unbind` 解除当前世界绑定，解除后自动清除可能残留的强制暂停状态

## MIDI 信息使用

- 音符力度 `Velocity`：映射到播放音量

- CC7 通道音量、CC11 表情：与力度共同参与音量计算

- `GetChords()` / `Chord`：用于吉他和弦识别，失败时回退到 50ms 时间分组

- `InstrumentNameEvent` / `ProgramNameEvent`：作为主旋律识别提示

- `GetDuration<TTimeSpan>()`：计算歌曲总时长

- `NoteName` / `Octave`：保留原始音名与八度，用于调试和后续音域策略

- Terraria 可播放音高约为 C4-C6（MIDI 60-84），超出范围的音符会按八度折叠；`NoteName` / `Octave` 不改变实际音域，只提供原始信息

## 其他播放说明

- 本插件不适宜在世界物块过多的环境下播放，这是客户端的一个限制/Bug？

- 当世界物块过多时，在播放上可能会导致音符截断，爆音，无法修复或绕过，建议配合UTSL的子世界功能播放（UTSL最有用的一集）

- 该问题由破哦哦哦哦发现并验证（修了好久，原来这是一个Bug.......?)

- 冷知识：TerraAngel修改了音乐的相关播放逻辑，所以使用TerraAngel播放不会听到截断/爆音问题

- 在使用本插件播放的时候请不要让玩家弹奏乐器，不然你会听到怀疑人生的（乐）（也是poooo发现的）

### v1.4.5.5

- 修复高音污染问题：播放前/播放中若有人弹奏竖琴、铃铛、吉他斧等乐器，会改写客户端全局音高 `Main.musicPitch`，导致 MIDI 相应乐器的高音被"限制/跑调"，且需重启客户端才恢复
